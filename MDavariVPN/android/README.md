# MDavari VPN — اندروید (فاز A: اپ کمکی هوشمند)

اپ اندرویدی با همان ظاهر و همان منطق نسخه‌ی ویندوز:

- **دریافت لیست سرور از چند منبع** (سایت → مسیر جایگزین → API ونگیت → آینه‌های گیت‌هاب → کش)
- **تست پینگ واقعی (TCP)** روی همه‌ی سرورها به‌صورت موازی
- **نمایش کشور به فارسی، فیلتر کشور، فقط سرورهای فعال**
- **انتخاب هوشمند بهترین سرور** با یک لمس
- **تشخیص خودکار فعال شدن تونل VPN** (از طریق `NetworkCapabilities`) + تایمر و IP
- **ساخت پروفایل OpenVPN همان سرور** و پاس دادنش به اپ «OpenVPN for Android»
- **راهنمای L2TP/IPSec** برای وقتی که اپ OpenVPN نصب نیست
- تنظیمات (تایم‌اوت پینگ، پورت ۴۴۳، اتصال مجدد، ...) + **لاگ زنده**
- تب خرید/پشتیبانی نمایشی (QR/کیف پول TRC20 + کد دستگاه)

---

## چرا اندروید «SSTP» ندارد؟

سیستم اندروید پروتکل SSTP را به‌صورت داخلی ندارد (فقط PPTP/L2TP/IPSec و IKEv2 دارد). سرورهای `opengw.net` هم `vpn/vpn` را می‌پذیرند و معمولاً هم **OpenVPN** و هم **SSTP** ارائه می‌دهند. پس معقول‌ترین راه روی گوشی:

1. **این فاز (A):** اپ کمکی، سرور را انتخاب و کانفیگ OpenVPN همان سرور را می‌سازد و به اپ OpenVPN می‌دهد — عملاً یک لمس.
2. **فاز B (بعدی):** پیاده‌سازی تونل داخل خود اپ با `VpnService` تا بدون اپ جانبی کار کند.

## ساخت APK

نیازی به نصب Android Studio نیست؛ از GitHub Actions:

1. کل پروژه را در یک مخزن گیت‌هاب (Public) آپلود کن.
2. تب **Actions** → ورک‌فلوی **build-android-apk** → **Run workflow**.
3. چند دقیقه بعد از بخش **Artifacts** فایل `MDavariVPN-android-apk` را دانلود کن → داخلش `app-debug.apk` است.
4. فایل APK را روی گوشی نصب کن (اجازه‌ی «نصب از منابع نامشخص» را بده).

> روی گوشی هم اگر Android SDK داشتی: `cd android && gradle assembleDebug`

## پیش‌نیاز اپ جانبی (فاز A)

اپ رایگان و اپن‌سورس **OpenVPN for Android** (`de.blinkt.openvpn`) — اگر نصب نباشد، خود برنامه گزینه‌ی نصب را نشان می‌دهد. برای اتصال خودکار کامل: در تنظیمات آن اپ، اتصال خودکار (Connect on boot / Always-on) را روشن کن.

جایگزین بدون نصب هیچ اپی: راهنمای **L2TP/IPSec** (سرور: همان هاست، PSK/user/pass = `vpn`).

## ساختار کد

```
android/app/src/main/java/com/mdavari/vpn/
├── MainActivity.kt          منطق کامل برنامه و رابط کاربری
├── model/Server.kt          مدل سرور + نام فارسی کشورها
├── net/Sources.kt           ۵ منبع دریافت لیست + پارسر + کش
├── net/Pinger.kt            پینگ TCP موازی + گرفتن IP
├── vpn/ProfileBridge.kt     ساخت .ovpn + Intent به اپ OpenVPN + راهنمای L2TP
├── ui/ShieldView.kt         دکمه‌ی سپر با حلقه‌های چرخان (Canvas)
├── ui/ServerAdapter.kt      آداپتر لیست سرورها
└── util/…                   تنظیمات (Prefs) + ابزار فارسی (Fmt)
```

## نکات فنی
- `minSdk 23`, `targetSdk 34`, Kotlin 1.9.24, AGP 8.5.2
- بدون هیچ CDN یا کتابخانه‌ی سنگین؛ فقط `core-ktx` و `appcompat`
- همه‌ی درخواست‌های شبکه در نخ پس‌زمینه؛ رابط کاربری هیچ‌وقت قفل نمی‌شود
- پروفایل‌ها در `filesDir/profiles` ذخیره و با `FileProvider` به اپ OpenVPN داده می‌شوند
